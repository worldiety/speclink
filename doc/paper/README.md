# doc/paper

The paper *Annotate Only What Cannot Be Inferred* — the design of speclink, its
relation to publicly verifiable parts of ISO 26262, IEC 61508, DO-178C and
Automotive SPICE, and a delimitation from generator-side spec-driven tooling.

## Build

Built by hand, with [Typst](https://typst.app) 0.15 or later:

```
cd doc/paper
typst compile main.typ speclink.pdf
```

**`speclink.pdf` is committed on purpose and must not be built in CI.**
The document is generated by hand and the committed file is what gets linked
to, so the artefact a reader receives is the one an author looked at. A CI job
that rebuilt it would either produce a file nobody reviewed or make the build
depend on a Typst toolchain and a font set for no gain. Regenerate it in the
same commit as any change under `doc/paper/`, and do not add a workflow for it.

## Layout

| path | what it is |
|---|---|
| `main.typ` | the document: metadata, section order, bibliography |
| `acmart.typ` | an independent ACM-like layout. **Not** an official ACM template |
| `sections/*.typ` | one fragment per section; content only, no page setup |
| `refs.bib` | the bibliography — verified sources only |
| `speclink.pdf` | the committed output |

## The rules the sources were written under

These are kept because the paper was written largely by language models and the
controls are the only reason its citations can be trusted.

| path | what it is |
|---|---|
| `STYLE.md` | the binding authoring contract for a section fragment |
| `CITATION-GUIDE.md` | per source: what it may and may not be used to support |
| `research/standards.md` | verified facts on ISO 26262, IEC 61508, DO-178C, IEC 62304, Automotive SPICE |
| `research/traceability-literature.md` | verified peer-reviewed literature |
| `research/related-tools.md` | verified vendor and community sources |
| `research/AUDIT.md` | an independent re-verification of every source. **Authoritative** |
| `ORCHESTRATION.md` | the cross-section defect list found during assembly |
| `REVIEW.md` | what the review pass changed, and what it could not |

`research/AUDIT.md` overrides the three research files wherever they disagree,
and its *MUST NOT BE CITED* list is binding. A source that could not be
retrieved during the session that recorded it is not in `refs.bib`.
